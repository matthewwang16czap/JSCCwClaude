WHAT CHANGED: at batch 8 the token arms used hybrid 11.2 GB and vit 1.6 GB.
vit was resized so that, like the hybrid, it fills a 3090 at batch 16 and
256 px. Batch 16 is now the default at 256 px.

  arm      size                                               params  est. peak
  hybrid   unchanged: the previous best AdaJSCC                12.5 M   ~21 GiB
  vit      patch 8 (1024 tokens per tile), width 768,         142.4 M   ~19 GiB
           10 blocks per side, 12 heads, 4-symbol tokens
  swin     unchanged baseline                                   5.3 M   ~16 GiB

The estimates are activation memory measured on CPU, calibrated on your three
batch-8 readings. Step 2 measures the real peaks, about a minute per arm.

GOTCHA: memory-matched is NOT compute- or parameter-matched. Per image, vit
costs ~6x the hybrid's FLOPs, with 11x its parameters, so its epochs will be
several times slower (step 2 prints ms/step). GPU 5 runs the previous small
size: read big against small before crediting size.

GOTCHA: stop the three batch-8 runs first. Every run below carries --tag w1,
so none of them can overwrite a batch-8 run directory in history/.

 0. UNPACK AND ONCE PER SESSION
--------------------------------------------------------------------------------

# stop the batch-8 runs: nvidia-smi lists their PIDs on GPUs 0-2
#   kill <pid> <pid> <pid>

cd ~/projects/jscc_clean && unzip -o ~/jscc_clean.zip && cd jscc
#   (the archive's top folder is jscc/. Unpack where the clean tree already

export JSCC_DATA_ROOT=$HOME
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True   # less fragmentation
COMMON="--trainset DIV2K --validset DIV2K --testset Kodak --img-size 256 \
  --batch-size 16 --channel-type awgn --snrs 1 4 7 10 13 --snr-range -2 22 \
  --valid-freq 40 --amp --training --tag w1"

--------------------------------------------------------------------------------
 1. CPU GATES — under a minute. All must pass.
--------------------------------------------------------------------------------

python -m pyflakes main.py engine.py configs data net utils tools
python tools/smoke.py            # ends with "all checks passed"
python tools/check_channel.py    # ends with "channel conventions hold"

--------------------------------------------------------------------------------
 2. GPU PROBE — about a minute per arm: real peak memory and speed at batch 16
--------------------------------------------------------------------------------

CUDA_VISIBLE_DEVICES=0 python tools/probe.py --backbone hybrid --batch-size 16 --amp
CUDA_VISIBLE_DEVICES=1 python tools/probe.py --backbone vit --batch-size 16 --amp
CUDA_VISIBLE_DEVICES=3 python tools/probe.py --backbone swin --batch-size 16 --amp

# Each prints params, peak reserved memory, ms/step and hours per 100k steps
# (= 2000 DIV2K epochs at batch 16). Keep "reserved" at or below ~22 GiB:
#   vit    above 22 -> append --depth 8 to its line in step 3    (~15-18 GiB)
#   hybrid above 22 -> append --batch-size 8 to its lines in step 3
#                      (accumulation keeps the effective batch at 16)

--------------------------------------------------------------------------------
 3. WAVE 1 — 2000 epochs, 6 cards
--------------------------------------------------------------------------------

# GPU 0 — hybrid: the previous best AdaJSCC, spread phase order.
CUDA_VISIBLE_DEVICES=0 nohup python main.py $COMMON --backbone hybrid \
  > w1_gpu0_hybrid.out 2>&1 &

# GPU 1 — vit: patch 8, width 768, 10 blocks per side.
CUDA_VISIBLE_DEVICES=1 nohup python main.py $COMMON --backbone vit \
  > w1_gpu1_vit.out 2>&1 &

# GPU 3 — the swin baseline under the SAME protocol (cosine LR, last
#   checkpoint). Earlier baseline numbers used a constant LR and best-of-N
#   selection: do not compare against them.
CUDA_VISIBLE_DEVICES=3 nohup python main.py $COMMON --backbone swin \
  > w1_gpu3_swin.out 2>&1 &

# GPU 4 — hybrid with the previous tree's raster phase order: isolates the one
#   deliberate change from the validated setup (spread).
CUDA_VISIBLE_DEVICES=4 nohup python main.py $COMMON --backbone hybrid \
  --phase-order raster > w1_gpu4_hybrid_raster.out 2>&1 &

# GPU 5 — the previous SMALL vit (~2.5 GiB): the control for the resize.
CUDA_VISIBLE_DEVICES=5 nohup python main.py $COMMON --backbone vit \
  --patch-size 16 --sym-per-token 16 --token-dim 384 --depth 6 --heads 6 \
  > w1_gpu5_vit_small.out 2>&1 &

# --- while it runs --------------------------------------------------------------
tail -n 2 w1_gpu*.out                  # img/s, loss, the diag check
grep "diag" w1_gpu1_vit.out | tail -3
#   "swapped" must fall well below "psnr" within the first few thousand steps;
#   if the three stay equal, the decoder has collapsed: stop it, send the log
grep "non-finite" w1_gpu*.out          # skipped optimiser steps: expect none
nvidia-smi                             # ~16-21 GiB on GPUs 0-4
ls history/                            # six new *_w1 directories

python tools/compare_runs.py history/swin_*_w1 history/hybrid_*_w1 \
  history/vit_*_w1 --test
